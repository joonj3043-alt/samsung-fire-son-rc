손성준 RC 홈페이지 v13 · 전체 디자인 통합본

[이번 버전 핵심]
- 홈과 모든 서브페이지의 헤더·메뉴·전화/문자 버튼을 동일한 구조로 통일
- 홈 기준 네이비/아이보리 톤, 둥근 버튼, 여백·타이포 규칙을 전 페이지에 적용
- 서브페이지 첫 화면을 홈과 연결되는 2단 구조로 재설계
- 각 페이지 성격에 맞는 요약 키워드로 복붙 느낌 최소화
- 전 페이지 공통 푸터와 모바일 전화/문자 바 통일
- RC 소개의 브랜드 카드에서 '교체 가능' 같은 미완성 표현 제거
- 기존 보험 안내 본문과 공식 링크, 숨은 보험금 안내 흐름은 유지

[실제 공개 직전 남은 항목]
1. 실제 도메인이 정해지면 js/config.js의 siteUrl 입력
2. sitemap.xml.template의 {SITE_URL}을 실제 도메인으로 바꿔 sitemap.xml 생성
3. robots.txt에 Sitemap: https://도메인/sitemap.xml 추가
4. iPhone Safari / Android Chrome에서 실제 화면 및 전화·문자 링크 확인
5. 삼성화재 내부 광고·준법 기준 최종 확인
6. 실제 손성준 RC 프로필 사진을 사용하기로 결정하면 RC 소개의 브랜드 카드만 실사진으로 교체

본 사이트는 손성준 RC 개인 상담 홈페이지이며 삼성화재 공식 홈페이지가 아닙니다.
